## How I work

- Check the data before trusting any result: duplicates, timestamps, gaps and bad values.
- Fix the rules for success before looking at the results, and report failures as well as successes.
- Keep work reproducible, with tests and data-quality checks.
- Be clear about limits: licensed market data isn't redistributed, and simulated results aren't live trading performance.
